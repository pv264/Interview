| Error                         | Meaning                                                     | Where the Problem Is                               | Common Causes                                                                          | First Checks                                                                        |
| ----------------------------- | ----------------------------------------------------------- | -------------------------------------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **500 Internal Server Error** | Application encountered an unexpected error                 | Application itself                                 | Bugs, exceptions, database connection failures, configuration issues                   | Application logs (`kubectl logs`, `journalctl`, `docker logs`)                      |
| **502 Bad Gateway**           | Gateway/proxy received an invalid response from the backend | Between gateway and backend                        | Crashed application, wrong port, invalid HTTP response, TLS mismatch                   | Pod status, service endpoints, target group health, backend listening port          |
| **503 Service Unavailable**   | Service is temporarily unavailable                          | Backend is unavailable or has no healthy instances | No running pods, pods not ready, maintenance, selector mismatch, all targets unhealthy | `kubectl get pods`, `kubectl get endpoints`, deployment replicas, ALB target health |
| **504 Gateway Timeout**       | Gateway timed out waiting for backend                       | Backend is too slow to respond                     | Slow database queries, slow APIs, network latency, long-running requests               | Application response time, database performance, timeout settings, logs             |



---------------------------------------------------------------

| Error Code                         | Meaning                                                   | Where the Problem Is                 | Common Causes                                                              | First Checks                                                                      |
| ---------------------------------- | --------------------------------------------------------- | ------------------------------------ | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| **200 OK**                         | Request completed successfully                            | No issue                             | Request processed normally                                                 | Verify response body if needed                                                    |
| **201 Created**                    | A new resource was created successfully                   | No issue                             | Successful POST request                                                    | Verify resource creation in the database or API response                          |
| **301 Moved Permanently**          | Resource has permanently moved to a new URL               | Web server or redirect configuration | HTTP to HTTPS redirect, changed URL structure                              | Check web server (Nginx/Apache) or ALB redirect rules                             |
| **302 Found (Temporary Redirect)** | Resource is temporarily available at another URL          | Web server or application            | Login redirects, temporary routing changes                                 | Check application redirect logic and web server configuration                     |
| **400 Bad Request**                | Server cannot process the request because it is malformed | Client request                       | Invalid JSON, missing required fields, incorrect parameters                | Validate request payload, API documentation, request headers                      |
| **401 Unauthorized**               | Authentication is required or credentials are invalid     | Authentication layer                 | Missing JWT, expired token, invalid API key                                | Verify Authorization header, token validity, authentication service               |
| **403 Forbidden**                  | User is authenticated but does not have permission        | Authorization layer                  | IAM policy, RBAC restrictions, insufficient permissions                    | Check IAM policies, Kubernetes RBAC, user roles, application authorization        |
| **404 Not Found**                  | Requested resource does not exist                         | Application or routing               | Incorrect URL, missing API endpoint, deleted resource                      | Verify API path, Ingress rules, application routes, resource existence            |
| **405 Method Not Allowed**         | HTTP method is not supported for the requested resource   | Application or API                   | Using GET instead of POST, DELETE instead of PUT                           | Verify API documentation, supported HTTP methods, route configuration             |
| **408 Request Timeout**            | Client took too long to send the request                  | Client or network                    | Slow internet, interrupted upload, idle connection                         | Check client network, upload size, timeout configuration                          |
| **409 Conflict**                   | Request conflicts with the current resource state         | Application or database              | Duplicate records, concurrent updates, version conflicts                   | Check database records, unique constraints, optimistic locking                    |
| **429 Too Many Requests**          | Client exceeded the allowed request rate                  | API Gateway, Load Balancer, WAF      | API rate limiting, excessive traffic, bot activity                         | Check rate-limit configuration, API Gateway logs, WAF logs, client retry behavior |
| **500 Internal Server Error**      | Application encountered an unexpected error               | Application                          | Exceptions, bugs, failed database connections, configuration errors        | Application logs, container logs, database connectivity, stack trace              |
| **501 Not Implemented**            | Requested functionality is not supported by the server    | Server or application                | API endpoint not implemented, unsupported HTTP method                      | Verify application version, API documentation, server capabilities                |
| **502 Bad Gateway**                | Gateway received an invalid response from the backend     | Gateway ↔ Backend                    | Application crash, wrong backend port, invalid HTTP response, TLS mismatch | Backend logs, pod health, service endpoints, target group health                  |
| **503 Service Unavailable**        | Service is temporarily unavailable                        | Backend service                      | No healthy pods, maintenance, scaling event, selector mismatch             | Pod status, readiness probes, endpoints, deployment replicas, ALB target health   |
| **504 Gateway Timeout**            | Gateway timed out waiting for the backend                 | Backend or downstream service        | Slow database, slow API, network latency, long-running queries             | Application response time, database performance, timeout settings, logs           |
