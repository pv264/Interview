| Error                         | Meaning                                                     | Where the Problem Is                               | Common Causes                                                                          | First Checks                                                                        |
| ----------------------------- | ----------------------------------------------------------- | -------------------------------------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **500 Internal Server Error** | Application encountered an unexpected error                 | Application itself                                 | Bugs, exceptions, database connection failures, configuration issues                   | Application logs (`kubectl logs`, `journalctl`, `docker logs`)                      |
| **502 Bad Gateway**           | Gateway/proxy received an invalid response from the backend | Between gateway and backend                        | Crashed application, wrong port, invalid HTTP response, TLS mismatch                   | Pod status, service endpoints, target group health, backend listening port          |
| **503 Service Unavailable**   | Service is temporarily unavailable                          | Backend is unavailable or has no healthy instances | No running pods, pods not ready, maintenance, selector mismatch, all targets unhealthy | `kubectl get pods`, `kubectl get endpoints`, deployment replicas, ALB target health |
| **504 Gateway Timeout**       | Gateway timed out waiting for backend                       | Backend is too slow to respond                     | Slow database queries, slow APIs, network latency, long-running requests               | Application response time, database performance, timeout settings, logs             |
